# MRP-система учёта склада

Веб-приложение для учёта товаров на складе и автоматического расчёта себестоимости продукции. Позволяет вести учёт ингредиентов, управлять рецептурой блюд и отслеживать расход сырья при производстве.

![Python](https://img.shields.io/badge/Python-3.10+-blue)
![Django](https://img.shields.io/badge/Django-4.1-green)
![SQLite](https://img.shields.io/badge/SQLite-database-lightgrey)

## Возможности

- Учёт ингредиентов на складе (название, вес, цена за кг)
- Управление рецептурой блюд (состав, норма расхода)
- Автоматический расчёт себестоимости блюда на основе рецепта
- Списание ингредиентов при производстве продукции
- Авторизация пользователей
- Админ-панель Django для управления данными

## Стек

- **Python 3.10+**
- **Django 4.1** — веб-фреймворк
- **SQLite** — база данных
- **HTML/CSS/JavaScript** — фронтенд

## Установка и запуск

1. Клонировать репозиторий:

```bash
git clone https://github.com/makel0ve/sklad.git
cd sklad
```

2. Установить зависимости:

```bash
pip install -r requirements.txt
```

3. Создать `.env` файл:

```bash
cp .env.example .env
```

Сгенерировать SECRET_KEY можно командой:

```bash
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

4. Применить миграции и создать суперпользователя:

```bash
python manage.py migrate
python manage.py createsuperuser
```

5. Запустить сервер:

```bash
python manage.py runserver
```

6. Открыть в браузере: `http://127.0.0.1:8000`

## Как работает

**Ингредиенты** — добавляются через админ-панель (`/admin`). Указывается название, вес на складе и цена за килограмм.

**Блюда** — создаются через админ-панель. Для каждого блюда задаётся рецепт — список ингредиентов с нормой расхода.

**Себестоимость** — рассчитывается автоматически на основе рецепта: сумма (цена ингредиента × норма расхода).

**Производство** — при указании количества произведённых порций ингредиенты автоматически списываются со склада.
